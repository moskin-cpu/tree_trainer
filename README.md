# Tree Trainer

An interactive, dependency-free trainer for practicing:

- Binary search tree insertion and deletion
- AVL insertion, deletion, and rotations
- Red-black insertion, rotations, recoloring, and invariant checks
- 2-3-4 tree insertion, node splitting, key grouping, and invariant checks

Open `index.html` in a browser to start. Choose a tree type, practice mode, and difficulty, then drag the numbered nodes into place. In Red-Black mode, click or tap a placed node to switch it between red and black.

In 2-3-4 mode, build a tree by inserting values in badge order and splitting full nodes before descending. Each rectangular node holds one to three sorted keys. Alter challenges start from a valid 2-3-4 tree and ask you to insert one more key.
